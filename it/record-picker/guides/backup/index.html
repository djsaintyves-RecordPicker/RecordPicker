Esegui il backup della tua raccolta

Conserva una copia datata della tua collezione Record Picker prima di un'importazione di grandi dimensioni, un cambio di dispositivo o una modifica importante. La sincronizzazione mantiene i dispositivi allineati; non sostituisce un backup indipendente, poiché anche le eliminazioni possono essere sincronizzate.

1. Scegli un backup completo o un'esportazione leggibile

Uno CSV leggibile è utile in un foglio di calcolo. Un'esportazione JSON leggibile contiene metadati di raccolta strutturata. Queste esportazioni non sono intercambiabili con un backup Record Picker completo: l'estensione del file da sola non dice cosa include il file.

Nelle recenti versioni di iPhone e iPad, la schermata di backup distingue i backup completi dalle esportazioni leggibili dei record posseduti e dalla lista dei desideri. Utilizza l'opzione di backup completo per il ripristino, se disponibile nella versione installata. Controlla le opzioni su Mac e Windows separatamente anziché dare per scontato menu identici o compatibilità dei file.

2. Salva il file in un posto facilmente reperibile

Scegli la destinazione nel selettore file di sistema e attendi il completamento dell'esportazione. Mantieni il nome file proposto o aggiungi una data che identifichi lo stato della raccolta. Individua il file salvato e conserva un'altra copia indipendentemente dal dispositivo che stai proteggendo.

3. Verificare prima di dover ripristinare

Per esportazioni leggibili, apri il file e controlla diversi record, la raccolta posseduta o la destinazione della lista dei desideri e il numero di righe previsto. Laddove l'app offre la verifica del backup, utilizzala per controllare il backup senza modificare la raccolta corrente. Trovare un file non è sufficiente per stabilire se è completo o compatibile.

4. Leggere attentamente la scelta del ripristino

Laddove vengono offerte l'unione e la sostituzione, l'unione conserva i record che esistono solo sul dispositivo corrente; replace li rimuove e ripristina lo stato del backup. Salvare una nuova copia prima del ripristino e leggere la conferma. Sui dispositivi sincronizzati, una sostituzione può influire sulla raccolta condivisa. Non eseguire una sostituzione semplicemente per verificare se un file si apre.

Un'utile lista di controllo di backup

Dovresti conoscere il percorso del file, la sua data, se si tratta di un backup completo o di un'esportazione leggibile e quale versione installata può leggerlo. Conserva questa copia indipendente anche quando la sincronizzazione sembra integra.
