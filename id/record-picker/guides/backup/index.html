Cadangkan koleksi Anda

Simpan salinan tertanggal koleksi Record Picker Anda sebelum melakukan impor besar-besaran, perubahan perangkat, atau pengeditan besar. Sinkronisasi menjaga perangkat tetap selaras; itu tidak menggantikan cadangan independen, karena penghapusan juga dapat disinkronkan.

1. Pilih cadangan lengkap atau ekspor yang dapat dibaca

CSV yang dapat dibaca berguna dalam spreadsheet. Ekspor JSON yang dapat dibaca berisi metadata koleksi terstruktur. Ekspor ini tidak dapat dipertukarkan dengan cadangan lengkap Record Picker: ekstensi file saja tidak memberi tahu Anda apa yang termasuk dalam file tersebut.

Di versi iPhone dan iPad terbaru, layar pencadangan membedakan pencadangan lengkap dari ekspor catatan milik dan daftar keinginan yang dapat dibaca. Gunakan opsi pencadangan lengkap untuk pemulihan, bila tersedia dalam versi yang Anda instal. Periksa opsi pada Mac dan Windows secara terpisah daripada mengasumsikan kompatibilitas menu atau file yang sama.

2. Simpan file di tempat yang dapat Anda temukan kembali

Pilih tujuan di pemilih file sistem dan tunggu hingga ekspor selesai. Pertahankan nama file yang diusulkan atau tambahkan tanggal yang mengidentifikasi status pengumpulan. Temukan file yang disimpan dan simpan salinan lainnya secara terpisah dari perangkat yang Anda lindungi.

3. Verifikasi sebelum Anda perlu memulihkan

Untuk ekspor yang dapat dibaca, buka file dan periksa beberapa catatan, koleksi yang dimiliki atau tujuan daftar keinginan, dan jumlah baris yang diharapkan. Jika aplikasi menawarkan verifikasi cadangan, gunakan aplikasi tersebut untuk memeriksa cadangan tanpa mengubah koleksi saat ini. Menemukan file saja tidak cukup untuk membuktikan bahwa file tersebut lengkap atau kompatibel.

4. Baca pilihan pemulihan dengan cermat

Jika penggabungan dan penggantian ditawarkan, penggabungan menyimpan catatan yang hanya ada di perangkat saat ini; replace akan menghapusnya dan memulihkan status cadangan. Simpan salinan baru sebelum memulihkan dan baca konfirmasinya. Pada perangkat yang disinkronkan, penggantian dapat memengaruhi koleksi bersama. Jangan melakukan penggantian hanya untuk menguji apakah suatu file terbuka.

Daftar periksa cadangan yang berguna

Anda harus mengetahui lokasi file, tanggalnya, apakah itu cadangan lengkap atau ekspor yang dapat dibaca, dan versi terinstal mana yang dapat membacanya. Simpan salinan independen ini meskipun sinkronisasi tampak sehat.
