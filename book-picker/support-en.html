Book Picker support

Start with an empty library

Use + to add a book. A title is enough to begin; you can fill in other details later. You can also import a BookBuddy CSV export or a Book Picker JSON backup from Tools.

Import and back up

Create a CSV export in BookBuddy, then select that file in Book Picker. Reimporting updates original fields while retaining protected personal changes. Original imported fields remain available in book details.

Export a JSON backup before an important operation. Restoring merges the backup with your existing library; it does not replace the entire library, and local choices remain prioritized. An unreadable file is not automatically overwritten; follow the error message and keep a copy of the original file.

ISBN lookup and scanning

In Add a book, enter an ISBN and request a lookup. Suggested information remains a preview until you apply it and save the book. Scanning is optional and depends on iPhone or iPad compatibility and camera permission. If scanning or the network is unavailable, use manual entry.

Why are no books available?

Check reading status, favorites, genre, tag, and reading list filters, as well as draw exclusions. Books in Trash are excluded. When every eligible book has been drawn, reset the cycle to begin again. Book of the day uses unread books that are not on loan.

Tags, lists, and Trash

Tags lets you browse assignments and find books without tags. Long-press or right-click for management actions. Removed tags can be restored. Batch editing lets you search, check several books, and review the selection before saving. Trash keeps books available for restoration.

Covers

Long-press or right-click a cover to open the available actions. You can choose an image, paste, import, or search for a cover. Remote loading needs Internet access. Check the remote cover setting if images do not appear. Device settings may restrict Photos or camera access.

Apple Watch and Mac

The watch uses the iPhone library. Open the apps on both devices and check that the watch is paired; the system may defer transfers. If Book Picker reports a pending sync, use its retry action. Mac has a separate library: use JSON export/import to transfer data when needed, taking merge behavior into account.

Personal data and deletion

A backup can include personal notes and loan details. Choose where to save or share it accordingly. Book Picker Trash is recoverable and does not permanently delete data. Manage local data through your operating system’s storage tools and exported copies at their saved locations.

Contact support

Email support@recordpicker.app. Include your device model, system version, Book Picker version, and the steps to reproduce the issue. A screenshot can help after personal information has been hidden. Please do not send your entire library if a description is sufficient.
