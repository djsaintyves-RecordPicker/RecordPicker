Assistance Book Picker

Commencer avec une bibliothèque vide

Utilisez le bouton + pour ajouter un livre. Un titre suffit pour commencer ; les autres renseignements peuvent être ajoutés ensuite. Vous pouvez aussi importer un export CSV BookBuddy ou une sauvegarde JSON Book Picker depuis le menu Outils.

Importer et sauvegarder

Dans BookBuddy, créez un export CSV, puis sélectionnez ce fichier dans Book Picker. Le réimport actualise les champs d’origine et conserve les modifications personnelles protégées. Les champs importés restent consultables dans la fiche.

Exportez une sauvegarde JSON avant une opération importante. Une restauration fusionne la sauvegarde avec la bibliothèque existante : elle ne remplace pas toute la bibliothèque, et les choix locaux restent prioritaires. Un fichier illisible n’est pas écrasé automatiquement ; suivez le message d’erreur et conservez une copie du fichier d’origine.

ISBN et scanner

Dans Ajouter un livre, saisissez un ISBN puis demandez une recherche. Les informations proposées restent un aperçu tant que vous ne les appliquez pas et n’enregistrez pas le livre. Le scanner est optionnel et dépend de la compatibilité de l’iPhone ou de l’iPad et de l’autorisation caméra. Si le scanner ou le réseau est indisponible, utilisez la saisie manuelle.

Pourquoi aucun livre n’est proposé ?

Vérifiez les filtres de statut, favoris, genre, tag et liste de lecture, ainsi que les exclusions du tirage. Un livre placé dans la corbeille ne participe pas aux choix. Lorsque tous les livres éligibles ont été tirés, réinitialisez le cycle pour recommencer. Lecture du jour utilise les livres non lus et non prêtés.

Tags, listes et corbeille

La page Tags permet de consulter les associations et de retrouver les livres sans tag. Un appui long ou clic droit donne accès aux actions de gestion. Les tags retirés peuvent être restaurés. L’édition en lot permet de rechercher, cocher plusieurs livres et vérifier la sélection avant Enregistrer. La corbeille conserve les livres et permet de les restaurer.

Couvertures

Utilisez un appui long ou clic droit sur une couverture pour accéder aux actions disponibles. Vous pouvez choisir une image, coller, importer ou rechercher une couverture. Les chargements distants nécessitent Internet. Vérifiez leur activation dans les réglages si les images ne s’affichent pas. Les réglages de l’appareil peuvent limiter Photos ou la caméra.

Apple Watch et Mac

La montre utilise la bibliothèque de l’iPhone. Ouvrez les apps sur les deux appareils et vérifiez que la montre est jumelée ; les transferts peuvent être différés par le système. Si Book Picker signale une synchronisation en attente, utilisez sa commande de nouvelle tentative. Le Mac garde une bibliothèque indépendante : transférez les données par export/import JSON si nécessaire, en tenant compte de la fusion.

Données personnelles et suppression

Une sauvegarde peut contenir des notes et informations de prêt personnelles. Choisissez son emplacement et son partage en conséquence. La corbeille de Book Picker est réversible et ne supprime pas définitivement les données. Gérez les données locales avec les outils de stockage de votre système et les copies exportées à leur emplacement.

Contacter l’assistance

Écrivez à support@recordpicker.app. Indiquez le modèle de votre appareil, sa version du système, la version de Book Picker et les étapes permettant de reproduire le problème. Une capture peut aider après masquage des informations personnelles. N’envoyez pas votre bibliothèque complète si une description suffit.
