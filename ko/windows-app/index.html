Record Picker

Windows

Windows 11, x64 또는 ARM64 PC에서 레코드판과 CD 컬렉션을 정리하세요. Microsoft Store에서 Record Picker를 다운로드하세요.

Microsoft StoreRecord Picker Studio
⊞

당신의 컬렉션. 다음은 들어보세요.

CSV 컬렉션을 가져오거나 레코드를 추가하고, 앨범을 검색하고, Random Pick, Mood Pick 또는 Today’s Pick로 재생할 항목을 선택하세요.

최대 100개의 소유 레코드로 무료로 시작하세요. Light는 무제한 기록 및 가져오기를 잠금 해제합니다. Pro는 고급 도구를 추가합니다. 별도의 일회성 구매입니다. 구매하기 전에 Microsoft Store에서 현지 가격을 확인하세요.

  • 필터를 따르는 그래프레코드 간의 문서화된 링크를 탐색하고, 각 경로 뒤에 있는 증거를 이해하고, 편집 가능한 듣기 여정으로 경로를 저장하세요.
  • 여러 레코드를 함께 이동정확한 변경 사항을 미리 검토한 후 필터링된 기록을 물리적 저장 위치로 이동합니다.
  • 더욱 신뢰할 수 있는 청취 통찰력청취 필터와 컬렉션 스토리는 확인된 청취와 선택 및 재생 실행을 구별합니다.
  • 당신의 컬렉션이 이야기를 말해줍니다비공개 로컬 컬렉션 스토리를 만들고 신중하게 한정된 PNG 카드로 저장하거나 공유하세요.
  • 명확성과 신뢰성그래프 성능, 검토 정리, 번역, 여러 백업 및 복구 워크플로우가 개선되었습니다.

Windows 11의 Record Picker 3.0.1

아래 캡처는 출시된 Windows 앱의 프랑스어 인터페이스를 보여줍니다.

Record Picker: Light 또는 Pro

iPhone · iPad · Apple Watch · Windows · 3.1.1 / Mac · 3.0.1 — 지금 이용 가능

음반 100장까지 무료

Light — €2.99, 일회성 구매

Random Pick, Today’s Pick 및 Mood Pick이 포함된 간단한 앨범 카탈로그입니다. 컬렉션이나 가져오기의 앨범에는 제한이 없습니다. 즐겨찾기, 검색, 백업, 복원이 포함됩니다.

Pro — €9.99, 일회성 구매

Light의 모든 것 외에 Listening Journeys, 컬렉션 그래프, 고급 통계, 리뷰 및 키워드용 도구, 일괄 메타데이터 업데이트, 실제 버전의 메모 및 사진이 포함되어 있습니다. 기존 Pro 구매는 권리를 유지하며 Pro 가격은 변경되지 않습니다.

구독 없이 일회성 구매입니다. 매장에서는 구매 전 해당 통화로 가격을 표시합니다. 음악 서비스 구독은 별개입니다. 실제 버전의 비공개 사진은 현재 기기에 남아 있습니다.
