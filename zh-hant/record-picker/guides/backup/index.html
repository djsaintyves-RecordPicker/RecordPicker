備份您的收藏

在進行大量匯入、裝置變更或重大編輯之前，請保留 Record Picker 系列的帶日期的副本。同步使設備保持一致；它不會取代獨立備份，因為刪除也可以同步。

1.選擇完整備份或可讀匯出

可讀的 CSV 在電子表格中很有用。可讀取的 JSON 匯出包含結構化集合元資料。這些匯出不能與完整的 Record Picker 備份互換：檔案副檔名本身並不能告訴您檔案包含哪些內容。

在最新的 iPhone 和 iPad 版本中，備份畫面將完整備份與自有記錄和願望清單的可讀匯出區分開來。如果您安裝的版本中可用，請使用完整備份選項進行還原。分別檢查 Mac 和 Windows 上的選項，而不是假設相同的選單或檔案相容性。

2. 將文件儲存到可以再次找到的地方

在系統檔案選擇器中選擇目標位置並等待匯出完成。保留建議的檔案名稱或新增標識收集狀態的日期。找到已儲存的檔案並保留另一個副本，而與您要保護的裝置無關。

3. 需要恢復前進行驗證

對於可讀匯出，請開啟檔案並檢查幾筆記錄、擁有的集合或願望清單目標以及預期的行數。如果應用程式提供備份驗證，請使用它來檢查備份而不更改當前集合。找到一個文件並不足以證明它是完整的或相容的。

4.仔細閱讀恢復選項

在提供合併和替換的情況下，合併保留僅存在於目前裝置上的記錄；替換會刪除它們並還原備份狀態。在恢復之前保存一份新副本並閱讀確認資訊。在同步設備上，替換可能會影響共用集合。不要僅為了測試文件是否開啟而執行替換。

有用的備份清單

您應該知道檔案位置、日期、是否是完整備份或可讀匯出，以及哪個安裝版本可以讀取它。即使同步看起來正常，也要保留此獨立副本。
