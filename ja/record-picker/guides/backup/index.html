コレクションをバックアップする

大規模なインポート、デバイスの変更、または大幅な編集を行う前に、Record Picker コレクションの日付付きコピーを保管してください。同期によりデバイスの調整が維持されます。削除も同期できるため、独立したバックアップに代わるものではありません。

1. 完全なバックアップまたは読み取り可能なエクスポートを選択します

読みやすい CSV はスプレッドシートで便利です。読み取り可能な JSON エクスポートには、構造化されたコレクションのメタデータが含まれています。これらのエクスポートは、完全な Record Picker バックアップと互換性がありません。ファイル拡張子だけでは、ファイルに何が含まれているかが分かりません。

最近の iPhone および iPad バージョンでは、バックアップ画面で完全なバックアップと、所有レコードやウィッシュリストの読み取り可能なエクスポートが区別されます。インストールされているバージョンで利用可能な場合は、復元に完全バックアップ オプションを使用してください。同一のメニューやファイル互換性を前提とするのではなく、Mac と Windows のオプションを個別に確認してください。

2. ファイルを再度見つけられる場所に保存します

システム ファイル ピッカーで宛先を選択し、エクスポートが完了するまで待ちます。提案されたファイル名をそのまま使用するか、収集状態を識別する日付を追加します。保存されたファイルを見つけて、保護しているデバイスとは別に別のコピーを保持します。

3. 復元する前に確認する

読み取り可能なエクスポートの場合は、ファイルを開いて、いくつかのレコード、所有されているコレクションまたはウィッシュリストの宛先、および予想される行数を確認します。アプリでバックアップ検証が提供されている場合は、それを使用して、現在のコレクションを変更せずにバックアップを確認します。ファイルを見つけるだけでは、そのファイルが完全であるか互換性があるかを確認するのに十分ではありません。

4. 復元の選択をよく読んでください。

マージと置換が提供されている場合、マージでは現在のデバイスにのみ存在するレコードが保持されます。 replace はそれらを削除し、バックアップ状態を復元します。復元する前に新しいコピーを保存し、確認を読んでください。同期されたデバイスでは、交換が共有コレクションに影響を与える可能性があります。ファイルが開くかどうかをテストするためだけに置換を実行しないでください。

便利なバックアップ チェックリスト

ファイルの場所、日付、完全なバックアップか読み取り可能なエクスポートか、インストールされているどのバージョンがそれを読み取ることができるかを知っておく必要があります。同期が正常に行われているように見える場合でも、この独立したコピーを保持してください。
