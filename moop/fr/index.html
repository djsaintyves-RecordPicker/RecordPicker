Vos informations, sous votre contrôle.

La bibliothèque est enregistrée dans l’application. Vous choisissez les imports, exports et partages. La synchronisation iCloud facultative entre Mac et iPhone est désactivée par défaut et nécessite un compte Apple avec iCloud. Les fichiers JSON restent disponibles pour les transferts. La Watch utilise l’iPhone associé.

La version publique démarre sans catalogue tiers préchargé. Les films et séries se regardent sur les services externes : leurs offres, pays et abonnements s’appliquent.

Un achat définitif, sans abonnement.

Téléchargement gratuit. Démarrez explicitement un essai gratuit facultatif de 7 jours, sans facturation automatique. Ensuite, un achat définitif unique débloque Moovie Picker sur iPhone et iPad avec le même compte Apple. La version Mac est encore en attente de validation et n’est pas annoncée comme disponible. Prix de base : 4,99 € ; le prix local est affiché dans la fenêtre d’achat Apple. Aucun abonnement. Vous pouvez restaurer les achats ; cela ne synchronise pas votre bibliothèque.
