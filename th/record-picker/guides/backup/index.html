สำรองคอลเลกชันของคุณ

เก็บสำเนาคอลเลกชัน Record Picker ของคุณไว้ก่อนที่จะนำเข้าจำนวนมาก เปลี่ยนแปลงอุปกรณ์ หรือแก้ไขครั้งใหญ่ การซิงโครไนซ์ช่วยให้อุปกรณ์อยู่ในแนวเดียวกัน ไม่ได้แทนที่การสำรองข้อมูลอิสระ เนื่องจากการลบสามารถซิงโครไนซ์ได้เช่นกัน

1. เลือกการสำรองข้อมูลที่สมบูรณ์หรือการส่งออกที่สามารถอ่านได้

CSV ที่อ่านได้มีประโยชน์ในสเปรดชีต การส่งออก JSON ที่อ่านได้ประกอบด้วยข้อมูลเมตาของคอลเลกชันที่มีโครงสร้าง การส่งออกเหล่านี้ไม่สามารถใช้แทนกันได้กับการสำรองข้อมูล Record Picker ที่สมบูรณ์: นามสกุลไฟล์เพียงอย่างเดียวไม่ได้บอกคุณว่าไฟล์นั้นมีอะไรบ้าง

ใน iPhone และ iPad เวอร์ชันล่าสุด หน้าจอสำรองข้อมูลจะแยกการสำรองข้อมูลที่สมบูรณ์ออกจากการส่งออกบันทึกที่เป็นเจ้าของและสิ่งที่อยากได้ที่อ่านได้ ใช้ตัวเลือกการสำรองข้อมูลที่สมบูรณ์สำหรับการกู้คืน เมื่อพร้อมใช้งานในเวอร์ชันที่ติดตั้งของคุณ ตรวจสอบตัวเลือกบน Mac และ Windows แยกกัน แทนที่จะคิดว่าเมนูเหมือนกันหรือความเข้ากันได้ของไฟล์

2. บันทึกไฟล์ไว้ที่ใดที่คุณสามารถหาได้อีกครั้ง

เลือกปลายทางในตัวเลือกไฟล์ระบบและรอให้การส่งออกเสร็จสิ้น คงชื่อไฟล์ที่เสนอไว้หรือเพิ่มวันที่ที่ระบุสถานะการรวบรวม ค้นหาไฟล์ที่บันทึกไว้และเก็บสำเนาอื่นไว้โดยไม่ขึ้นอยู่กับอุปกรณ์ที่คุณกำลังปกป้อง

3. ตรวจสอบก่อนที่คุณจะต้องการกู้คืน

สำหรับการส่งออกที่อ่านได้ ให้เปิดไฟล์และตรวจสอบบันทึกต่างๆ คอลเลกชันที่เป็นเจ้าของหรือปลายทางสิ่งที่อยากได้ และจำนวนแถวที่คาดหวัง ในกรณีที่แอปมีการตรวจสอบการสำรองข้อมูล ให้ใช้เพื่อตรวจสอบข้อมูลสำรองโดยไม่ต้องเปลี่ยนคอลเลกชันปัจจุบัน การค้นหาไฟล์ไม่เพียงพอที่จะพิสูจน์ได้ว่าไฟล์นั้นสมบูรณ์หรือเข้ากันได้

4. อ่านตัวเลือกการคืนค่าอย่างละเอียด

ในกรณีที่มีการเสนอการผสานและการแทนที่ การผสานจะเก็บบันทึกที่มีอยู่บนอุปกรณ์ปัจจุบันเท่านั้น แทนที่ ลบออกและเรียกคืนสถานะการสำรองข้อมูล บันทึกสำเนาใหม่ก่อนที่จะกู้คืนและอ่านคำยืนยัน บนอุปกรณ์ที่ซิงโครไนซ์ การเปลี่ยนทดแทนอาจส่งผลต่อคอลเลกชันที่แชร์ อย่าทำการแทนที่เพียงเพื่อทดสอบว่าไฟล์เปิดอยู่หรือไม่

รายการตรวจสอบการสำรองข้อมูลที่มีประโยชน์

คุณควรทราบตำแหน่งของไฟล์ วันที่ของไฟล์ ไม่ว่าจะเป็นการสำรองข้อมูลทั้งหมดหรือการส่งออกที่อ่านได้ และเวอร์ชันที่ติดตั้งไว้ใดที่สามารถอ่านได้ เก็บสำเนาอิสระนี้ไว้แม้ว่าการซิงโครไนซ์จะดูมีประสิทธิภาพดีก็ตาม
