Windows

Οργανώστε τη συλλογή βινυλίων και CD σε υπολογιστές Windows 11, x64 ή ARM64. Κατεβάστε το Record Picker από το Microsoft Store.

Microsoft StoreRecord Picker Studio
⊞

Η συλλογή σας. Η επόμενη ακρόαση.

Εισαγάγετε μια συλλογή CSV ή προσθέστε τα αρχεία σας, αναζητήστε τα άλμπουμ σας και επιλέξτε τι θα παίξετε με τα Random Pick, Mood Pick ή Today’s Pick.

Ξεκινήστε δωρεάν με έως και 100 ιδιόκτητους δίσκους. Το Light ξεκλειδώνει απεριόριστες εγγραφές και εισαγωγές. Το Pro προσθέτει προηγμένα εργαλεία. Είναι ξεχωριστές εφάπαξ αγορές. Ελέγξτε την τοπική τιμή σε Microsoft Store πριν αγοράσετε.

  • Ένα γράφημα που ακολουθεί τα φίλτρα σαςΕξερευνήστε τεκμηριωμένους συνδέσμους μεταξύ εγγραφών, κατανοήστε τα στοιχεία πίσω από κάθε διαδρομή και αποθηκεύστε μια διαδρομή ως επεξεργάσιμο Listening Journey.
  • Μετακινήστε πολλές εγγραφές μαζίΜετακινήστε τις φιλτραρισμένες εγγραφές σε μια φυσική τοποθεσία αποθήκευσης αφού ελέγξετε μια προεπισκόπηση των ακριβών αλλαγών.
  • Πιο αξιόπιστες γνώσεις ακρόασηςΤα φίλτρα ακρόασης και οι ιστορίες συλλογής διακρίνουν τις επιβεβαιωμένες ακρόαση από τις επιλογές και τις εκκινήσεις αναπαραγωγής.
  • Η συλλογή σας λέει την ιστορία τηςΔημιουργήστε μια ιδιωτική, τοπική ιστορία συλλογής και αποθηκεύστε την ή μοιραστείτε την ως μια προσεκτικά περιορισμένη κάρτα PNG.
  • Σαφήνεια και αξιοπιστίαΗ απόδοση γραφήματος, η εκκαθάριση κριτικών, οι μεταφράσεις και πολλές ροές εργασιών δημιουργίας αντιγράφων ασφαλείας και ανάκτησης έχουν βελτιωθεί.

Record Picker: Light ή Pro

iPhone · iPad · Apple Watch · 3.1.1 / Mac · Windows · 3.0.1 — Διαθέσιμο τώρα

Δωρεάν έως 100 δίσκους

Light — 2,99 €, εφάπαξ αγορά

Ένας απλός κατάλογος άλμπουμ με Random Pick, Today’s Pick και Mood Pick. Δεν υπάρχει όριο στα άλμπουμ στη συλλογή ή στις εισαγωγές σας. Περιλαμβάνει αγαπημένα, αναζήτηση, δημιουργία αντιγράφων ασφαλείας και επαναφορά.

Pro — 9,99 €, εφάπαξ αγορά

Τα πάντα στο Light, συν Listening Journeys, γραφήματα συλλογής, προηγμένα στατιστικά στοιχεία, εργαλεία για κριτικές και λέξεις-κλειδιά, μαζικές ενημερώσεις μεταδεδομένων και σημειώσεις και φωτογραφίες των φυσικών εκδόσεων σας. Οι υπάρχουσες αγορές Pro διατηρούν τα δικαιώματά τους και η τιμή Pro παραμένει αμετάβλητη.

Εφάπαξ αγορά, χωρίς συνδρομή. Το κατάστημά σας εμφανίζει την τιμή στο νόμισμά σας πριν από την αγορά. Οι συνδρομές σε υπηρεσίες μουσικής είναι ξεχωριστές. Οι ιδιωτικές φωτογραφίες των φυσικών εκδόσεων σας παραμένουν επί του παρόντος στη συσκευή σας.
