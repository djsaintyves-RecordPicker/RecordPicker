# Record Picker 1.9 website screenshots

These are real light-mode captures of Record Picker 1.9. They are prepared for
the website switch that will happen only after version 1.9 is publicly
available on every announced App Store platform.

## Publication set

| File | Source | Size | Website use |
| --- | --- | --- | --- |

| `en-us/ipad-collection-grid.png` | iPad Pro 13-inch simulator, app commit `8de462d`, version 1.9 build 13 | 1200 × 1600 | Collection grid on iPad |
| `en-us/mac-today-pick.png` | Distributed macOS app, version 1.9 build 6 | 1280 × 900 | Main 1.9 Mac feature |
| `en-us/mac-overview.png` | Distributed macOS app, version 1.9 build 6 | 1280 × 900 | Optional Mac overview |
| `fr/iphone-random-pick.png` | iPhone 17 Pro simulator, app commit `8de462d`, version 1.9 build 13 | 1206 × 2622 | Optional French overview |

The simulator collection was copied into isolated capture devices. The images
show real album artwork but no contact details, account identifiers, location
data, or other personal information. Status bars use a stable light-mode state.

## Editorial rules

- Never use onboarding, tutorial, walkthrough, empty-state, or dark-mode images.
- Never publish an image with mixed interface languages.
- Keep the original aspect ratio and use `object-fit: contain` for iPad and Mac.
- Do not stretch phone captures into desktop-width columns.
- The French Today's Pick view from build 13 is intentionally excluded because
  one action remained untranslated (`Mark as played`).
- The iPad Today's Pick sheet is intentionally excluded because its layout leaves
  too much unused space for an effective website illustration.
- Do not change public 1.9 availability until App Store distribution is
  confirmed for iPhone, iPad, Apple Watch, and Mac.
