Faça backup da sua coleção

Mantenha uma cópia datada de sua coleção Record Picker antes de uma grande importação, uma mudança de dispositivo ou uma grande edição. A sincronização mantém os dispositivos alinhados; ele não substitui um backup independente, porque as exclusões também podem ser sincronizadas.

1. Escolha um backup completo ou uma exportação legível

Um CSV legível é útil em uma planilha. Uma exportação JSON legível contém metadados de coleção estruturados. Essas exportações não são intercambiáveis ​​com um backup Record Picker completo: uma extensão de arquivo por si só não informa o que o arquivo inclui.

Nas versões recentes do iPhone e iPad, a tela de backup distingue os backups completos das exportações legíveis de registros próprios e da lista de desejos. Use a opção de backup completo para recuperação, quando disponível na sua versão instalada. Verifique as opções no Mac e no Windows separadamente, em vez de assumir menus idênticos ou compatibilidade de arquivos.

2. Salve o arquivo em algum lugar que você possa encontrar novamente

Escolha o destino no seletor de arquivos do sistema e aguarde o término da exportação. Mantenha o nome do arquivo proposto ou adicione uma data que identifique o estado da coleção. Localize o arquivo salvo e guarde outra cópia independentemente do dispositivo que você está protegendo.

3. Verifique antes de precisar restaurar

Para exportações legíveis, abra o arquivo e verifique vários registros, a coleção de propriedade ou destino da lista de desejos e o número esperado de linhas. Onde o aplicativo oferece verificação de backup, use-o para verificar o backup sem alterar a coleção atual. Encontrar um arquivo não é suficiente para estabelecer se ele está completo ou compatível.

4. Leia atentamente a escolha de restauração

Onde a mesclagem e a substituição são oferecidas, a mesclagem mantém registros que existem apenas no dispositivo atual; replace os remove e restaura o estado de backup. Salve uma nova cópia antes de restaurar e leia a confirmação. Em dispositivos sincronizados, uma substituição pode afetar a coleção compartilhada. Não execute uma substituição apenas para testar se um arquivo é aberto.

Uma lista de verificação de backup útil

Você deve saber a localização do arquivo, sua data, se é um backup completo ou uma exportação legível e qual versão instalada pode lê-lo. Mantenha esta cópia independente mesmo quando a sincronização parecer saudável.
