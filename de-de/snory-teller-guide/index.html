Bereiten Sie sich auf eine Nacht vor und verstehen Sie den Bericht

LEITFADEN · Snory Teller

Bevor Sie beginnen

  1. Platzieren Sie Ihr angeschlossenes iPhone auf einer stabilen Oberfläche in der Nähe des Bettes, sodass das Mikrofon nicht behindert wird. Halten Sie es von Bettzeug fern.
  2. Führen Sie in dieser Position einen kurzen Test durch. Überprüfen Sie, ob die Mikrofonanimation auf Ton reagiert. Die Animation zeigt, dass das Mikrofon Ton empfängt. Ob Schnarchen erkannt wird, muss gesondert geprüft werden.
  3. Wenn Sie Benachrichtigungen verwenden, tragen Sie Ihre Uhr, führen Sie den in der App bereitgestellten Test durch und sperren Sie dann Ihr iPhone. Überprüfen Sie den Alarmbeginn und das Stoppen separat.
  4. Fangen Sie an zuzuhören. Wenn Sie die Eingangsverstärkung anpassen, ändern Sie jeweils eine Einstellung und wiederholen Sie den gleichen Test. Eine höhere Verstärkung garantiert keine bessere Erkennung.

Lesen Sie die Morgenzahlen der Reihe nach

Analysierte Zeit: Überprüfen Sie zunächst die Hördauer und Unterbrechungen. Eine fast vollständige Abdeckung bedeutet, dass die Analyse lief und nicht jedes Schnarchen erkannt wurde.

Geschätztes Schnarchen: Dies sind Geräusche, die als Schnarchen eingestuft werden. Kurze oder vereinzelte Erkennungen ergeben möglicherweise nie eine bestätigte Episode.

Warnungen: Unterscheiden Sie zwischen eingereichten Anfragen, verfügbaren Bestätigungen und dem, was Sie tatsächlich empfunden haben. Keine Anfragen bedeuten, dass die Erkennung keine Warnung ausgelöst hat.

Vergleichen Sie, ohne voreilige Schlüsse zu ziehen

Beachten Sie die Platzierung, die Mikrofonverstärkung, das Aufwachen und, wenn Sie ein Bett teilen, die Erfahrung Ihres Partners. Vergleichen Sie mehrere Nächte unter ähnlichen Bedingungen. Die App kann nicht erkennen, wer schnarcht; Eine Pause nach einer Warnung beweist nicht, dass die Warnung sie verursacht hat.
