Wählen Sie einen Datensatz aus, ohne sich im Kreis zu drehen

Wählen Sie ein Album aus, das Sie jetzt tatsächlich abspielen können, und hören Sie dann mit dem Stöbern auf. Record Picker hilft dabei, eine Sammlung in eine Hörentscheidung zu verwandeln; Das Zeichnen einer Schallplatte und das Anhören sind getrennte Aktionen.

1. Beginnen Sie mit einer Sammlung, die Sie kennen

Fügen Sie einige eigene Alben hinzu oder importieren Sie Ihre Sammlung und überprüfen Sie dann Künstler, Titel und Formate. Bewahren Sie Schallplatten, die Sie kaufen möchten, in der Wunschliste auf, damit Sie sie von den zu Hause verfügbaren Schallplatten unterscheiden können.

2. Halten Sie die Auswahl breit genug

Nutzen Sie die Genre-, Jahres-, Favoriten- oder Ausschlusssteuerungen, die Ihre Version tatsächlich bietet. Beginnen Sie mit einer nützlichen Einschränkung, anstatt jeden Filter zu kombinieren. Eine kleine Sammlung mit vielen Ausschlüssen hinterlässt möglicherweise keinen berechtigten Datensatz.

3. Zeichnen Sie eine Aufzeichnung oder beginnen Sie mit einer Stimmung

Random Pick schöpft aus berechtigten Datensätzen. Mood Pick bietet einen weiteren Ausgangspunkt, sofern verfügbar; Seine Fähigkeiten hängen vom Gerät und der installierten Version ab. Wählen Sie den Ansatz, der zum jeweiligen Zeitpunkt passt, und prüfen Sie dann das vorgeschlagene Album, bevor Sie es abspielen.

4. Wenn kein Vorschlag vorliegt

Überprüfen Sie, ob die Sammlung eigene Datensätze enthält, lockern Sie Filter und Ausschlüsse und lesen Sie alle Meldungen zum aktuellen Zeichnungszyklus. Ein bereits gezeichneter Datensatz kann in diesem Zyklus nicht verfügbar sein. Ein leeres Ergebnis bedeutet nicht automatisch, dass Ihre Sammlung gelöscht wurde.

Nach der Auswahl

Spielen Sie das Album ab, wenn es Ihnen passt. Nehmen Sie eine tatsächliche Hörsitzung mit den in Ihrer Version verfügbaren Steuerelementen auf oder behalten Sie das Album für ein anderes Mal in Listen Later. Die Ziehungshistorie zeichnet Vorschläge auf; es sollte nicht als Beweis dafür gewertet werden, dass jedes vorgeschlagene Album gehört wurde.
