Importieren Sie eine Discogs-Sammlung

Verschieben Sie Ihre Discogs-Sammlung mit einem CSV-Export nach Record Picker. Beginnen Sie mit einem kleinen Beispiel, damit Sie das Ziel, die Editionen und die vorgeschlagenen Änderungen überprüfen können, bevor Sie alles importieren.

1. Fordern Sie Ihren Discogs-Export an

Öffnen Sie in Ihrer Discogs-Sammlung das Einstellungsmenü und wählen Sie „Meine Sammlung exportieren“. Wählen Sie auf der Exportseite „Erfassung und Datenexport anfordern“ aus. Discogs bereitet die Datei vor und benachrichtigt Sie, wenn sie fertig ist. Laden Sie CSV herunter und behalten Sie das Original unverändert.

2. Schützen Sie Ihre bestehende Sammlung

Erstellen Sie vor einem großen Import eine datierte Sicherung oder einen Export Ihrer vorhandenen Record Picker-Sammlung und prüfen Sie, ob Sie diese finden können. Arbeiten Sie an einer Kopie des Discogs CSV, wenn Sie es bearbeiten. Ein Discogs CSV ist kein vollständiges Backup Ihrer Record Picker-Daten.

3. Wählen Sie das Ziel und sehen Sie sich die Vorschau an

Öffnen Sie den CSV-Import in Record Picker und wählen Sie Ihre Datei aus. Wählen Sie Ihre eigene Sammlung oder Ihre Wunschliste bewusst aus. Erkannte Discogs-Spalten können automatisch zugeordnet werden; Überprüfen Sie die Spaltenzuordnung, wenn Sie von der App dazu aufgefordert werden, insbesondere Interpret, Titel, Jahr und Format.

Lesen Sie vor der Bestätigung die Vorschau: Ergänzungen, Aktualisierungen, Datensätze bereits identischer und ähnlicher Ausgaben, die hinzugefügt werden müssen. Überprüfen Sie die vorgeschlagenen Änderungen, anstatt davon auszugehen, dass jede Zeile einen neuen Datensatz erstellt. Ähnliche Albumtitel beweisen nicht, dass es sich bei zwei Schallplatten um dieselbe Edition oder physische Kopie handelt.

4. Überprüfen Sie einige Alben, bevor Sie den Rest importieren

Verwenden Sie zunächst eine kleine Stichprobe und vergleichen Sie dann die importierten Künstler, Titel, Editionen und Ziele mit dem ursprünglichen CSV. Wenn das Ergebnis falsch ist, stoppen Sie den Vorgang und überprüfen Sie die Datei und zeigen Sie eine Vorschau an, bevor Sie fortfahren. Wenn alle Werte in einer Spalte erscheinen, überprüfen Sie das CSV-Trennzeichen. Vermeiden Sie es, den vollständigen Import wiederholt zu bestätigen, während Sie eine Nichtübereinstimmung untersuchen.

Nach dem Import

Überprüfen Sie, ob Ihre Alben in der vorgesehenen Liste angezeigt werden. Behalten Sie den Original-CSV und Ihr datiertes Backup und verwenden Sie dann die folgenden Anleitungen, um Ihre Sammlung zu sichern, Ihre nächste Platte auszuwählen oder Alben wiederzuentdecken, die Sie in letzter Zeit nicht abgespielt haben.
