Entdecken Sie vergessene Alben neu

Nutzen Sie Ihre Sammlung und Hörnotizen, um etwas auszuwählen, das Sie in letzter Zeit nicht gespielt haben. Ein Album ohne aufgezeichnete Anhörungen kann neu importiert werden: Eine fehlende Historie beweist nicht, dass es noch nie gehört wurde.

1. Trennen Sie Vorschläge vom tatsächlichen Zuhören

Der Ziehungsverlauf zeigt die von der App vorgeschlagenen Datensätze an. Die Hörinformationen spiegeln die von Ihnen aufgezeichneten Sitzungen wider. Überprüfen Sie zunächst, welche Informationen in Ihrer installierten Version verfügbar sind und wie konsequent Sie diese genutzt haben.

2. Entdecken Sie einen Teil Ihrer Sammlung

Wählen Sie ein Genre oder einen Zeitraum aus, den Sie vernachlässigt haben, und durchsuchen Sie dann diese Datensätze oder verwenden Sie die verfügbaren Auswahlsteuerungen. Random Pick kann innerhalb der in Frage kommenden Datensätze einen neuen Vorschlag unterbreiten, es sollte jedoch nicht davon ausgegangen werden, dass automatisch die am wenigsten gespielten Alben bevorzugt werden.

3. Bewahren Sie eine Entdeckung für den richtigen Moment auf

Wenn Sie es jetzt nicht anhören können, bewahren Sie das Album in Listen Later auf, sofern verfügbar. Fügen Sie eine nützliche Notiz hinzu, anstatt eine Hörsitzung aufzuzeichnen, die noch nicht stattgefunden hat. Überprüfen Sie Interpret, Titel und Ausgabe, wenn ein importierter Datensatz schwer zu erkennen ist.

4. Erstellen Sie einen Verlauf, den Sie verwenden können

Nachdem Sie tatsächlich zugehört haben, zeichnen Sie die Sitzung mit den Steuerelementen Ihrer Version auf. Überprüfen Sie Ihre Entdeckungen nach mehreren Sitzungen, anstatt die Sammlung anhand einer einzigen Ziehung zu beurteilen. Der Nutzen Ihres Hörverlaufs hängt von den Sitzungen ab, die Sie aufzeichnen, und nicht nur von der Anzahl der Vorschläge.

Vor der Neuorganisation des Katalogs

Bewahren Sie eine datierte Sicherung auf, bevor Sie viele Datensätze ändern oder eine überarbeitete Datei importieren. Verwenden Sie die Backup- und Discogs-Anleitungen unten und kehren Sie dann mit einer kleinen Hörauswahl zur Sammlung zurück, anstatt den gesamten Katalog auf einmal zu ändern.
