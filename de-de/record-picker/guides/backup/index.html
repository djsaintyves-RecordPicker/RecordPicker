Sichern Sie Ihre Sammlung

Bewahren Sie vor einem großen Import, einem Gerätewechsel oder einer größeren Bearbeitung eine datierte Kopie Ihrer Record Picker-Sammlung auf. Durch die Synchronisierung bleiben die Geräte aufeinander abgestimmt. es ersetzt kein eigenständiges Backup, da Löschungen auch synchronisiert werden können.

1. Wählen Sie eine vollständige Sicherung oder einen lesbaren Export

Ein lesbarer CSV ist in einer Tabellenkalkulation nützlich. Ein lesbarer JSON-Export enthält strukturierte Sammlungsmetadaten. Diese Exporte sind nicht mit einem vollständigen Record Picker-Backup austauschbar: Eine Dateierweiterung allein sagt Ihnen nicht, was die Datei enthält.

In neueren iPhone- und iPad-Versionen unterscheidet der Backup-Bildschirm vollständige Backups von lesbaren Exporten der eigenen Datensätze und der Wunschliste. Nutzen Sie für die Wiederherstellung die vollständige Backup-Option, sofern diese in Ihrer installierten Version verfügbar ist. Überprüfen Sie die Optionen auf Mac und Windows separat, anstatt identische Menüs oder Dateikompatibilität anzunehmen.

2. Speichern Sie die Datei an einem Ort, an dem Sie sie wiederfinden können

Wählen Sie das Ziel in der Systemdateiauswahl und warten Sie, bis der Export abgeschlossen ist. Behalten Sie den vorgeschlagenen Dateinamen bei oder fügen Sie ein Datum hinzu, das den Sammlungsstatus angibt. Suchen Sie die gespeicherte Datei und bewahren Sie unabhängig vom Gerät, das Sie schützen, eine weitere Kopie auf.

3. Überprüfen Sie, bevor Sie eine Wiederherstellung durchführen müssen

Für lesbare Exporte öffnen Sie die Datei und überprüfen Sie mehrere Datensätze, das Ziel der eigenen Sammlung oder der Wunschliste sowie die erwartete Anzahl von Zeilen. Wenn die App eine Backup-Überprüfung bietet, können Sie diese verwenden, um das Backup zu überprüfen, ohne die aktuelle Sammlung zu ändern. Das Auffinden einer Datei reicht nicht aus, um festzustellen, ob sie vollständig oder kompatibel ist.

4. Lesen Sie die Wiederherstellungsauswahl sorgfältig durch

Wenn Zusammenführen und Ersetzen angeboten werden, werden beim Zusammenführen Datensätze gespeichert, die nur auf dem aktuellen Gerät vorhanden sind. Ersetzen entfernt sie und stellt den Sicherungsstatus wieder her. Speichern Sie vor der Wiederherstellung eine neue Kopie und lesen Sie die Bestätigung. Auf synchronisierten Geräten kann sich ein Austausch auf die gemeinsame Sammlung auswirken. Führen Sie eine Ersetzung nicht nur durch, um zu testen, ob eine Datei geöffnet wird.

Eine nützliche Backup-Checkliste

Sie sollten den Speicherort der Datei und ihr Datum kennen, wissen, ob es sich um eine vollständige Sicherung oder einen lesbaren Export handelt und welche installierte Version sie lesen kann. Behalten Sie diese unabhängige Kopie auch dann bei, wenn die Synchronisierung einwandfrei erscheint.
