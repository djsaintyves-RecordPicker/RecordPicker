Зробіть резервну копію своєї колекції

Зберігайте застарілу копію вашої колекції Record Picker перед великим імпортом, зміною пристрою чи великим редагуванням. Синхронізація підтримує узгодженість пристроїв; це не замінює незалежну резервну копію, оскільки видалення також можуть синхронізуватися.

1. Виберіть повну резервну копію або доступний для читання експорт

Читабельний CSV корисний у електронній таблиці. Зрозумілий експорт JSON містить структуровані метадані колекції. Ці експорти не взаємозамінні з повною резервною копією Record Picker: лише розширення файлу не повідомляє вам, що містить файл.

В останніх версіях для iPhone та iPad екран резервного копіювання відрізняє повні резервні копії від доступних для читання експортів власних записів і списку бажань. Використовуйте опцію повного резервного копіювання для відновлення, якщо вона доступна у встановленій версії. Перевірте параметри на Mac і Windows окремо, а не припускайте ідентичні меню або сумісність файлів.

2. Збережіть файл де-небудь, де його можна буде знову знайти

Виберіть місце призначення в системному засобі вибору файлів і дочекайтеся завершення експорту. Залиште запропоновану назву файлу або додайте дату, яка визначає стан колекції. Знайдіть збережений файл і збережіть іншу копію незалежно від пристрою, який ви захищаєте.

3. Перевірте перед відновленням

Для читабельного експорту відкрийте файл і перевірте кілька записів, призначену колекцію чи список бажань, а також очікувану кількість рядків. Якщо програма пропонує перевірку резервної копії, використовуйте її, щоб перевірити резервну копію, не змінюючи поточну колекцію. Знайти файл недостатньо, щоб переконатися, що він повний або сумісний.

4. Уважно прочитайте варіант відновлення

Якщо пропонуються злиття та заміна, злиття зберігає записи, які існують лише на поточному пристрої; replace видаляє їх і відновлює стан резервної копії. Збережіть нову копію перед відновленням і прочитайте підтвердження. На синхронізованих пристроях заміна може вплинути на спільну колекцію. Не виконуйте заміну лише для того, щоб перевірити, чи відкривається файл.

Корисний контрольний список для резервного копіювання

Ви повинні знати розташування файлу, його дату, чи є це повна резервна копія чи доступний для читання експорт, і яка встановлена ​​версія може його прочитати. Зберігайте цю незалежну копію, навіть якщо синхронізація здається нормальною.
