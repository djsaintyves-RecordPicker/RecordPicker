备份您的收藏

在进行大量导入、设备更改或重大编辑之前，保留 Record Picker 系列的带日期的副本。同步使设备保持一致；它不会取代独立备份，因为删除也可以同步。

1.选择完整备份或可读导出

可读的 CSV 在电子表格中很有用。可读的 JSON 导出包含结构化集合元数据。这些导出不能与完整的 Record Picker 备份互换：文件扩展名本身并不能告诉您文件包含哪些内容。

在最新的 iPhone 和 iPad 版本中，备份屏幕将完整备份与自有记录和愿望清单的可读导出区分开来。如果您安装的版本中可用，请使用完整备份选项进行恢复。分别检查 Mac 和 Windows 上的选项，而不是假设相同的菜单或文件兼容性。

2. 将文件保存到可以再次找到的地方

在系统文件选择器中选择目标位置并等待导出完成。保留建议的文件名或添加标识收集状态的日期。找到已保存的文件并保留另一个副本，而与您要保护的设备无关。

3. 需要恢复前进行验证

对于可读导出，请打开文件并检查几条记录、拥有的集合或愿望清单目标以及预期的行数。如果应用程序提供备份验证，请使用它来检查备份而不更改当前集合。找到一个文件并不足以证明它是完整的或兼容的。

4.仔细阅读恢复选项

在提供合并和替换的情况下，合并保留仅存在于当前设备上的记录；替换将删除它们并恢复备份状态。在恢复之前保存一份新副本并阅读确认信息。在同步设备上，替换可能会影响共享集合。不要仅仅为了测试文件是否打开而执行替换。

有用的备份清单

您应该知道文件位置、日期、是否是完整备份或可读导出，以及哪个安装版本可以读取它。即使同步看起来正常，也要保留此独立副本。
