Record Picker 1.8 让 iPhone、iPad、Apple Watch 和 Mac 使用统一的版本体系。

  • 区分应用可安全完成的修正与需要你决定的选项，并显示每条建议的来源和可信度。
  • 并排比较 MusicBrainz 与 Discogs 的冲突。修复队列可继续执行，并支持 CSV 报告和撤销。
  • 新增四步入门指南，介绍导入、数据质量、Random Pick、Mood Pick 和 Free/Pro。
  • 唱片详情会优先显示最初发行年份，同时保留所藏版本的准确年份。
