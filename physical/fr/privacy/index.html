Confidentialité

Comment Physical utilise vos données.

EnglishFrançais

La version actuelle

Physical est une application de renforcement pour adultes, en cours de développement. Elle fonctionne sans compte, SDK publicitaire ni outil d’analyse d’audience. Le programme est calculé sur votre iPhone. L’éditeur ne reçoit pas automatiquement votre questionnaire, vos séances, vos mesures, vos photos ou vos données Santé.

Données locales

Le questionnaire peut contenir l’âge, la taille, le poids, les objectifs, les disponibilités et des informations sur la santé ou les opérations. Ces réponses, le planning et les progrès sont conservés dans les fichiers de l’app. Les photos et les mesures sont facultatives. Physical demande l’exclusion des fichiers personnels des sauvegardes automatiques ; des sauvegardes antérieures peuvent conserver des copies. La suppression de l’app retire ses données locales, sans supprimer nécessairement ces copies. Les repères corporels peuvent être supprimés dans l’app.

Apple Santé

L’accès est facultatif et demandé via les autorisations Apple. La version actuelle lit les pas et les entraînements autorisés et peut enregistrer une séance terminée avec une durée confirmée. Elle n’importe pas encore le sommeil ou la fréquence cardiaque. Vous pouvez modifier les accès dans les réglages Santé. Supprimer Physical ne supprime pas automatiquement les séances déjà enregistrées dans Santé. Les données Santé ne servent pas au ciblage publicitaire.

Watch, widget et rappels

La Watch associée reçoit les informations nécessaires aux séances et transmet les validations à l’iPhone. Le widget reçoit un résumé du planning. Les rappels sont des notifications locales facultatives, sans mesures de santé. Vous pouvez les désactiver dans Physical ou les Réglages iOS. Les préférences et les tutoriels déjà lus sont mémorisés sur l’appareil.

Services externes et assistance

Ouvrir un lien Internet ou une page App Store vous met en relation avec le service concerné, soumis à sa propre politique. Ce site est hébergé sur GitHub Pages ; l’hébergeur peut traiter des informations techniques, notamment l’adresse IP, lors d’une visite. Ces pages Physical n’intègrent ni publicité, cookies applicatifs ni mesure d’audience. Si vous nous écrivez, votre adresse et le contenu du message sont utilisés pour répondre et suivre la demande. N’envoyez pas de dossier médical ou de données Santé : ils ne sont pas nécessaires à l’assistance technique.

Évolutions

Cette politique décrit les fonctionnalités actuelles. Toute introduction de publicité, d’un achat ou de nouvelles catégories Santé nécessitera une mise à jour des informations et, lorsque nécessaire, des autorisations avant utilisation.
